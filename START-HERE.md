# Every Shade: start here

Every Shade is a Rutgers University–New Brunswick student group that gives free skin cancer talks for New Jersey seniors, focused on how skin cancer looks on every skin tone. This folder holds everything the group needs to run talks, book them, measure them, and grow.

## How the pieces connect

Each talk produces three numbers that feed everything else: attendance, average quiz score before, and average quiz score after. Record them in the outreach tracker's row for that organization. The tracker's Dashboard totals them, and the result line ("attendees' quiz scores rose from X% to Y%, n = Z") goes into new pitches, chapter reports, and applications.
