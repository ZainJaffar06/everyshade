# Every Shade

Free skin cancer talks for every skin tone in New Jersey. A student group at Rutgers University–New Brunswick. Site: https://zainjaffar06.github.io/everyshade/

| Folder | What is in it |
|---|---|
| `index.html` | The public site (GitHub Pages) |
| `check/` | Free monthly skin self-check web tool: guided exam, body map, local-only photos, reminders. Educational, not diagnostic. Published at `/everyshade/check/` |
| `talk-kit/` | The senior talk: 20-slide deck with speaker notes, two-page large-print handout, pre/post quiz (paper + Zoom polls), scoring workbook, run of show. See `talk-kit/README.md` |
| `languages/` | Handout translations (Spanish, Hindi, Urdu, Gujarati, Haitian Creole, Korean). All six reviewed and signed off by native speakers. See `languages/REVIEW-GUIDE.md` |
| `outreach/` | NJ outreach engine: researched contact lists (`data/`), `tracker.xlsx` pipeline with dashboard, pitch templates, and `generate_pitches.py` for personalized drafts. Nothing is sent automatically |
| `toolkit/` | Chapter toolkit so students elsewhere can start "Every Shade at [School]". Ten Markdown sections plus a rendered page at `/everyshade/toolkit/` |
| `newsletter/` | Derm × AI weekly: style guide, topic backlog, drafted issues |

Content standard: every medical claim traces to the American Academy of Dermatology, the Skin Cancer Foundation, the CDC, or a cited peer-reviewed paper, and is reviewed by a physician advisor before use. We never diagnose. General health education only.
