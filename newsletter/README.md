# Derm × AI weekly

A short weekly post on one AI-in-dermatology or AI-in-medicine startup, paper, or trend. Public voice and portfolio piece for venture fellowships (Contrary, Insight) and derm/AI labs.

- `STYLE-GUIDE.md`: format, voice, hard rules, the Monday/Tuesday/Wednesday workflow.
- `TOPIC-BACKLOG.md`: 20 vetted topics with angles. Pick one a week.
- `issues/`: one Markdown file per issue, `YYYY-MM-DD-slug.md`. Issue 1 (DermaSensor) is drafted with `[verify]` tags on the claims to confirm against primary sources before publishing.
- `PUBLISHED.md`: log of published links (create on first publish).

Publishing: LinkedIn article plus a 3-line post (bottom of each issue), mirrored on Substack. Keep the canonical copy here.

To have Claude draft each Monday automatically, set up a scheduled task with the prompt in `WEEKLY-PROMPT.md`.
